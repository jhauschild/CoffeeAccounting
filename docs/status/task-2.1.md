## What changed
- `app/services/mail.py` (new). `MailMessage(to, subject, body, headers)`, `Mailer` protocol (`send(message)`), `build_message(*, to, subject, body, to_name=None)`, `to_email_message(message)` (RFC 5322 for file/smtp; re-sanitises headers), `extract_links(message)`.
  - Headers: `From` = address part of `MAIL_FROM` (fallback `noreply@localhost` when unset, dev only), `To`, `Auto-Submitted: auto-generated`. Subject and optional `to_name` pass `clean_header_text` (CR, LF, tab, all control/format chars, U+2028/2029 removed or turned into spaces; subject max 200). Recipient must be a plain `local@domain` (else `InvalidInput`), lower-cased. Body: control chars stripped, `\n` only.
  - Backends: `MemoryMailer` (`get_outbox()` returns a copy, `clear_outbox()`), `ConsoleMailer` (logger `app.mail`, logs `to` and subject only), `FileMailer` (dir from `MAIL_FILE_DIR`, 0700 dir, `*.eml` 0600, O_EXCL), `SmtpMailer` stub (raises `MailError("not_configured")`). `BACKENDS` dict is the factory slot: task 2.2 replaces `BACKENDS["smtp"]` (or the `SmtpMailer` class). `get_mailer()` raises `MailError("not_configured")` for non-smtp in production, even if settings were bypassed.
  - `MailError(category)` subclasses `ServiceError`, code `mail_error`; `.category` in `CATEGORIES`, `.message_key` = `mail.error.<category>` (all exist in strings). Unknown category becomes `other`. Message text is the category only. `categorize_exception(exc)` maps smtplib/ssl/socket/OS errors to categories for 2.2 to use.
  - Caps: `reserve_send(db, message, *, per_recipient_key=None, now=None)` checks global (`MAIL_MAX_PER_HOUR`, bucket `mail_global`/key `all`) and per recipient (6/hour, `MAIL_MAX_PER_RECIPIENT_PER_HOUR`, bucket `mail_rcpt`, key = HMAC-SHA256 hex of the lower-cased address with `derive_key("mail-recipient-rate")`) and records both hits, or raises `MailError("cap_exceeded", scope="global"|"recipient")` recording nothing. `send_mail(db, mailer, message, *, per_recipient_key=None)` = `reserve_send` + backend. `per_recipient_key` is the address string the recipient cap applies to; default is `message.to`. Pass the sponsor's/member's address explicitly if it differs. A reserved send counts even if the backend then fails.
  - Status: `get_status()` returns frozen `MailStatus(last_ok_at, last_failure_category, last_failure_at)` plus `.cap_reached` (last failure was the cap and no success since: the admin page can say "cap reached", not "mail broken"). `record_success/record_failure/reset_status`. Module-level, not persisted, per process.
  - `send_in_background(message, per_recipient_key=None, *, mailer=None) -> None | category`: for `BackgroundTasks.add_task(...)` after the commit. Opens its own `write_session()` for the caps only, commits, closes, THEN sends (SMTP never runs inside the write lock). Never raises; logs `mail not sent: <category>` only.
- `app/services/mail_templates.py` (new): `member_verification(token)`, `already_registered()` (no token; points to `/login` and "Forgot password"), `guest_sponsor_request(*, guest_display_name, guest_username, token)`, `password_reset(*, username, token, for_guest=False)` (`for_guest` appends a note that the mail goes to the sponsor), `guest_approved(*, guest_username)`, `guest_rejected(*, guest_username)`; each returns `(subject, body)`. Links: `{PUBLIC_BASE_URL}/verify/{token}` and `/reset/{token}` (token percent-encoded). Subjects are static (no user text); names in bodies are single-line. Validity text follows settings (`verification_ttl_hours`, `guest_approval_ttl_days`, `reset_ttl_minutes`; defaults read "24 hours", "7 days", "1 hour"). Combine with `build_message(to=..., subject=..., body=...)`.
- `app/strings_mail.py` (new, keys `mail.*`); `app/strings.py`: one-line merge of `strings_mail`.
