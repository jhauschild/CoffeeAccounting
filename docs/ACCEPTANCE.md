# Acceptance report (Definition of Done, PROMPT section 14)

Verified on branch `acceptance` (from `main`, commit f81e232) by running the application, not by reading code.
Environment: Linux, Python 3.13 (`/home/claude/venv`), no Docker daemon (the `docker` CLI exists, `docker info` fails), no reverse proxy.

Driving tools: `curl`, an `httpx` cookie-jar client (generating TOTP codes with `pyotp`), headless Chromium via Playwright, direct SQLite queries to cross-check every amount.

## Defects and observations (nothing was fixed)

- **D1 (low, secret hygiene).** A failing production configuration prints pydantic's `input_value={...}` fragment (head and tail of the settings dict). With a minimal environment the output ended with `'access_code': 'GoodCode-12345'`, i.e. a real `ACCESS_CODE` printed to stderr/container log when another setting (for example an http base URL) was wrong. Which keys show depends on dict order and truncation; with the full `.env.example` set a different run showed none. Suggest `hide_input_in_errors=True` or catching `ValidationError` and printing messages only.
- **D2 (low).** `HEAD` requests answer 405 on `/healthz`, `/readyz` and `/`. `curl -I` and uptime monitors using HEAD will report failure; the Docker healthcheck and README commands use GET and are fine.
- **O1.** A price of 0 is accepted by the admin form and CLI path (`allow_zero=True`); intended, but README says nothing about it, and a zero price silently records free coffees.
- **O2.** The access-code, registration (10 per hour per IP) and admin-login (5 per 15 minutes per user+IP) limits are easy to hit when scripting from one address; they worked as designed (HTTP 429) and affected this test run only.
- Not covered by this run: Docker image build/run and healthcheck, proxy examples, real phone scanning, printing, forced 500 page in production.

Test-harness side effects: `opencv-python-headless` was installed into a scratch directory outside the venv (`--target`) only to decode QR images; nothing in the repository or venv was changed.
